# 움직임 규칙 (베타 2.0부터)

> "끊기고 부자연스럽고 세련되지 않을 거면 아예 하지 마." — 사용자

움직임은 **무엇이 바뀌었는지 알려 줄 때만** 쓴다. 아래 네 가지 말고는 만들지 않는다. 새 움직임은 [움직임-버그-체크리스트.md](움직임-버그-체크리스트.md)를 통과해야 한다.

## 종류는 넷
| # | 이름 | 언제 | 모양 | 시간·곡선 |
|---|---|---|---|---|
| ① | **창** | 창(시트)이 열리고 닫힐 때 | 휴대폰: 아래에서 끝까지 올라오고 내려감 / 태블릿·PC: 가운데서 살짝 커지며 나타남 | 열림 380ms `sheet` · 닫힘 240ms `in` |
| ② | **다음으로** | 처음 설정 단계, 설정 쪽, 창 안 단계, 탭 바꾸기 | **가로 페이드**: 옛 것이 왼쪽으로 조금(24px) 가며 먼저 흐려지고, 새 것이 오른쪽에서 조금 들어오며 나타남. 뒤로는 반대. 두 글자가 겹쳐 보이는 순간이 없다(옛 것 0~40%, 새 것 30~100%) | 320ms `standard` |
| ③ | **나타남·사라짐** | 알림, 펼치기, 체크 표시 | 페이드(+위아래 8px) | 200ms `out` / 160ms `in` |
| ④ | **손에 붙는 것** | 유리 막대 방울, 창 끌기 | 손가락을 그대로 따라가고, 놓으면 **용수철**(살짝 지나쳤다 돌아옴, 5% 안쪽) | 용수철 반응 0.34~0.49초, 감쇠 0.72 |

## 곡선 (이것만)
| 이름 | 값 | 쓰임 |
|---|---|---|
| `standard` | cubic-bezier(.2, 0, 0, 1) | ② |
| `sheet` | cubic-bezier(.32, .72, 0, 1) | ① 열림 (아이폰 창) |
| `out` | cubic-bezier(.2, .8, .2, 1) | ③ 나타남 |
| `in` | cubic-bezier(.4, 0, 1, 1) | 사라짐 |

## 규칙
1. **속도 설정은 없다.** 움직임은 켜기/끄기만(기기의 '동작 줄이기'를 따름). 끄면 아무것도 움직이지 않고 바로 바뀐다.
2. 시간은 위 표의 값만. 같은 종류는 어디서나 같은 시간·곡선.
3. **반투명한 글자 두 겹 금지.** 바뀌는 두 화면은 시간을 나눠(②) 겹치지 않게 하거나, 위에 오는 것을 불투명하게.
4. 움직이는 것은 위치·크기·투명도만(배치를 다시 계산하지 않음). 스크롤 상자 **안의** 요소에 위치 움직임을 걸지 않는다(아이폰이 스크롤 범위를 다시 계산함 — 베타 1.1 영상).
5. 키프레임 몇 개를 직선으로 잇는 움직임 금지(등속 = 기계 같음). 손에 붙는 것은 용수철.
6. 처음 한 번만 하는 것: 설치 후 처음 여는 소개 움직임(약 3초, 누르면 넘어감). 그 뒤 시작 화면은 짧게(약 1초). 시작 화면이 걷힐 때는 **글자 먼저 사라지고 → 바탕이 걷힌다**.
7. 화면이 안 보일 때는 움직이지 않는다. 움직임이 멈춰도 사라지는 복사본은 반드시 지운다.

## 코드
- 모두 `src/app/motion.js`: `T`(시간), `E`(곡선), `play`, `axis`(②), `sheetIn/sheetOut`(①), `spring/lensFrames/glide`(④).
- 화면 코드에서 시간·곡선 숫자를 직접 쓰지 않는다.
