## 실행 방법
```
python serve.py                 # http://localhost:5173 → 실제 앱
                                # http://localhost:5173/docs/mockups/prototype.html → 프로토타입 버전 목록
python tools/fake_supabase.py   # 동기화 시험용 가짜 서버
powershell -File tools/node.ps1 tests/run-node.js   # 테스트 (PC에 Node가 없어서 VS Code의 Electron으로 실행)
```
설치·동기화 설정은 [설치와-동기화.md](설치와-동기화.md).

## 저장 방식 (실제 앱)
- 화면 코드는 프로토타입처럼 "한 덩어리 자료"를 쓴다.
- 저장할 때만 레코드마다 비교해서 **바뀐 것만** IndexedDB에 쓴다.
- 동기화는 레코드 단위로 한다. 같은 레코드는 나중에 고친 쪽이 이긴다.
- 두 기기에서 같은 과목을 따로 체크해도 진도 칸이 맞춰진다.
  - 할 일 기록을 보고 진도 칸을 다시 채운다(`reconcile`).
  - 시험하는 두 '기기'는 `localhost`와 `127.0.0.1`(저장 공간이 따로다).
- 기기마다 다른 것(디자인·글자·태블릿 배치)은 그 기기에만 둔다.
- 공부 가능 시간·쉬는 요일은 두 기기가 같이 쓴다.
