사용자 요청: "QR을 찍고 브라우저로만 들어가는 게 아니라, 그냥 앱 들어가듯이 하고 싶어."

|---|---|
| 미리 보기를 **따로 설치**할 수 있게 (`manifest-preview.webmanifest`: 이름 '미리 보기', 주황 아이콘) | 한 번 추가하면 홈 화면 아이콘으로 앱처럼 열림. 실제 앱(초록)과 색으로 구별 |
| 맨 위 주황 줄 오른쪽에 **'홈 화면에 추가 ›'** | 갤럭시는 누르면 바로 설치 창, 아이폰은 공유 › 홈 화면에 추가 안내 (기기에 맞는 것부터). 홈 화면 앱으로 열면 사라짐 |
| 미리 보기는 열 때마다 **새것인지 확인** (`preview-sw.js`) | GitHub Pages가 파일을 10분쯤 기억해 둠 → 올린 직후에도 최신 수정본이 보이게 |

## 2026-10-01 · 미리 보기 주소
사용자 요청: "수정하고 제출할 때는 내가 수정본을 먼저 볼 수 있게 올려 줘."

| 무엇 | 왜·어떻게 |
|---|---|
| **미리 보기 주소** https://arronkang.github.io/hoedok-planner/preview/ | 올리기 전에 폰·태블릿에서 직접 써 보고 결정할 수 있게 |
| 미리 보기는 실제 앱과 **기록이 완전히 따로** (저장 이름 앞에 `preview.`) | 같은 사이트라 저장 공간이 같음 → 이름을 나눠 섞이지 않게. 미리 보기에서 지우거나 바꿔도 실제 기록은 그대로 |
| 미리 보기에서는 로그인·동기화를 막음 | 실제 계정의 기록을 건드리지 않게 |
| 맨 위 주황색 줄 `미리 보기 · 올린 때 · 내용` | 지금 보는 게 미리 보기인지, 최신인지 알 수 있게 |
| 미리 보기 전용 서비스 워커(`preview-sw.js`) | 폰에 설치된 실제 앱이 미리 보기 주소를 가로채지 않게, 실제 앱의 오프라인 저장을 지우지 않게. 처음 한 번은 스스로 새로 열림 |
| `tools/preview.py` | 브랜치를 main의 `preview/` 폴더로만 올림. 실제 앱 파일은 그대로 → 폰에 '새 버전' 알림 없음 |

확인: PC에서 실제 앱의 서비스 워커를 켠 상태(폰과 같은 상황)로 미리 보기를 열어 봄 → 한 번 새로 열린 뒤 미리 보기 화면, 따로 저장(`preview.hoedok-planner`), 실제 앱 기록(과목 6·할 일 109)·설정·오프라인 저장 그대로.

## 2026-09-30 · 3차: 디자인 손보기 + 움직임
계획·검토 과정은 [개발-계획.md](개발-계획.md) '3차', 버그 점검은 [움직임-버그-체크리스트.md](움직임-버그-체크리스트.md).

**움직임 (부드러운 페이드)**
| 무엇 | 어떻게 |
|---|---|
| 창 열기 | 배경이 서서히 어두워지고 창이 살짝 올라오며 나타남 (태블릿은 제자리에서 살짝 커지며) |
| 창 닫기 | 서서히 사라짐. 사라지는 동안에도 뒤 화면을 바로 누를 수 있음 |
| 창에서 다른 창으로 | 앞 창이 흐려지며 뒤 창이 드러남 (배경은 그대로) |
| 탭 옮기기·과목 열기·날짜 바꾸기 | 새 화면이 부드럽게 나타남 (태블릿은 오른쪽 칸만) |
| 체크 | 동그라미가 채워지고 체크 표시가 그려지며, 제목에 형광펜이 왼쪽부터 그어짐. **방금 누른 것만** 움직임 |
| 진도·요약 막대 | 값이 바뀌면 부드럽게 늘어남 |
| 알림 | 서서히 나타났다 사라짐 |
| 더 보기·자세히 펼치기, 설정 안쪽, 달력 달 넘기기, 시험 정리 단계, 처음 설정 단계 | 새로 나온 부분만 서서히 |
| 밀어서 완료·내일로, 창 끌어내리기를 놓았을 때 | 제자리로 부드럽게 |

**설정** — 설정 › 화면 › 디자인 · 글자 · 움직임
- `움직이는 속도: 느긋하게 / 보통 / 빠르게 / 끄기` — 고르는 순간 아래 알림이 그 속도로 떠서 바로 느껴 볼 수 있음
- `화면을 옮길 때도 부드럽게` (켬/끔)
- 기기에서 '동작 줄이기'를 켜 둔 사람은 처음부터 끄기 (설정에 이유 한 줄)

**디자인**
| 무엇 | 왜 |
|---|---|
| 휴대폰·태블릿에서 누른 뒤 '마우스 올림' 색이 남던 것 없앰 | 누른 줄이 선택된 것처럼 보였음 |
| 누르는 동안 살짝 작아지거나 바탕이 짙어짐 (아이폰 포함) | 눌렸는지 알 수 있게 |
| 아래 탭: 지금 탭 아이콘 뒤에 둥근 표시 | 어느 탭인지 한눈에 |
| '모든 기록 지우고 처음부터'를 빨간 글씨로 | 되돌리기 어려운 동작은 다르게 |
| 작은 단추(＋·…·↑↓·되돌리기·시간)의 누르는 칸을 넓힘 (보이는 크기는 그대로) | 손가락으로 누르기 쉽게 |
| 달력 '시험·마감' 글씨 10.5 → 12px | 읽기 쉽게 |
| 설정 '파일로 내보내기' 설명을 한 줄로 | 휴대폰에서 두 줄로 꺾였음 |

확인: 노드 테스트 66개·브라우저 테스트 77개 통과, 움직임 체크리스트 자동 점검 4단계 × 휴대폰·태블릿 통과, 전수 점검 768가지 넘침 0.

## 2026-09-30 · 기능 추가 2차 (반복·마감·기간)
계획과 근거는 [개발-계획.md](개발-계획.md) '기능 추가 2차'. 오늘 첫 화면에 늘어난 것은 **해당할 때만 뜨는 한 줄** 하나뿐이다.

| 무엇 | 어디서 | 왜 |
|---|---|---|
| **반복하는 할 일**: 매일 / 요일마다. 켜 두면 앞으로 2주씩 저절로 들어감 | 할 일 › 더 보기 › 반복 | 영단어·학원 숙제를 날마다 새로 넣어야 했음 (원칙 3: 입력은 한 번) |
| 반복하는 일의 이름·시간·중요도를 바꾸면 다음 반복에도 반영. 메모·사진·마감일은 그날 것만 | 같은 곳 | 매번 고치지 않게 |
| 반복하는 일을 하루만 지우면 그날만 빠짐 / `반복 그만하기`(되돌리기 가능) | 같은 곳 | |
| 못 한 반복은 밀리지 않고 그날 기록으로만 남음 ('지난 날 못 끝낸 일'에 안 쌓임) | — | 매일 하는 일이 쌓이면 플래너가 버려짐 |
| 반복하는 일 모아 보기 | 오늘 › … › 반복하는 일 (있을 때만) | |
| **다가오는 마감** 한 줄: 마감이 3일 안인데 다른 날로 잡아 둔 일 → `오늘 하기` | 오늘 화면 위 (해당할 때만) · 달력에 `마감` 표시 | 다른 날로 잡은 수행평가는 마감이 다가와도 안 보였음 (원칙 6) |
| 돌아보기 기간: `한 주씩 / 시험 준비 전체` | 이번 주 돌아보기 | 문서 3-E '미룬 이유 누적' — 한 주씩만 볼 수 있었음 |
| 나눠 줄 때 그날 직접 넣은 일·반복하는 일 시간을 먼저 빼고 나눔 | 남은 계획 다시 나누기 | 반복하는 일이 생기면 공부 가능 시간을 넘겨 넣게 됨 |
| 할 일 자세히에 마감일과 '3일 남음' 표시 | 할 일 | |
| '파일로 내보내기' 아래 마지막으로 내보낸 날 | 설정 › 자료 | 동기화를 안 쓸 때 유일한 보호인데 언제 했는지 몰랐음 |
| '몇 번 할까요' → '하루에 몇 번' | 할 일 › 더 보기 | 새로 생긴 '반복'과 헷갈리지 않게 |

**안에서 바뀐 것**
- 저장소에 `repeats` 표 추가 (DB 버전 2). 서버 SQL은 그대로.
- 반복 할 일 번호 = `규칙번호.날짜` → 두 기기가 따로 만들어도 하나.
- 앱이 저절로 만든 반복 할 일은 '가장 오래된 시각'으로 저장 → 다른 기기에서 체크한 기록을 절대 덮어쓰지 않음.
- 옛 버전 앱이 모르고 지나친 기록을 받도록, DB 버전이 오르면 다음 동기화는 처음부터 다시 받음.
- DB를 올릴 때 다른 탭이 잠깐 막아도 바로 실패하지 않고 기다림.

확인: 노드 테스트 61개·브라우저 테스트 77개 통과(새로 11개), 새 화면·시트 336가지(디자인 3 × 밝게·어둡게 × 글자 2 × 14화면 × 휴대폰·태블릿) 오류·넘침 0, 가짜 서버로 두 기기 시험 — 규칙·반복 할 일 중복 없음, **B가 오프라인으로 만든 할 일이 A에서 체크한 기록을 덮어쓰지 않음**.

## 2026-09-30 · 화면 다듬기
화면을 하나씩 점검해서 찾은 문제를 고쳤다.

| 무엇 | 왜 |
|---|---|
| 오늘 화면: 과목마다 따로 있던 상자를 **한 장**으로 합치고, 과목은 제목줄로 나눔 | 상자 테두리·그림자가 과목 수만큼 겹쳐 어지럽고, 한 화면에 할 일이 적게 보였음 |
| 같은 과목 안의 구분선은 체크 동그라미 뒤에서 시작 | 과목 경계(전체 폭 선)와 구분되게 |
| 흐린 글씨(날짜·쪽수·설명) 색을 진하게 | 6가지 색 조합 모두 읽기 기준(4.5:1)에 못 미쳤음 (부드러움-밝게는 2.9:1) → 모두 4.6:1 이상 |
| **뒤로 가기 버튼**: 열린 창을 닫거나 한 단계 앞 화면으로 | 갤럭시 탭에서 뒤로 가기를 누르면 앱이 꺼졌음 |
| 휴대폰 창 위 손잡이 줄을 **끌어내리면 닫힘** | 손잡이 모양이 있는데 끌어도 안 닫혔음 |
| 설정 첫 화면을 **자주 쓰는 순서**로: 공부 → 계정 → 화면 → 자료. 디자인·보일 것은 한 단계 안으로 | 자주 쓰는 시험·과목·계정이 맨 아래에 있었음 |
| 태블릿·PC: 목록을 읽기 좋은 폭으로 제한, 오늘 화면 위에 ＋ 단추 | 넓은 화면에서 줄이 너무 길었고, 할 일 추가가 목록 맨 아래에만 있었음 |
| 휴대폰 시험 리포트: 과목마다 '공부한 것'과 '결과'를 위아래로 | 세 칸이 좁아서 글이 줄마다 꺾였음 |
| 키보드로 쓸 때 고른 곳에 테두리 | PC·키보드 사용 때 지금 위치가 안 보였음 |
| 할 일 상세에서 교재 이름이 두 번 나오던 것 | "2회독 · 평가문제집 / 평가문제집 p.31–40" |
| 나눠 보기의 시간 단추를 크게 | 손가락으로 누르기 어려웠음 |
| 처음 열 때 화면이 저절로 한 번 새로 고쳐지던 것 | 오프라인 저장이 처음 켜질 때도 새로 고쳤음 |

확인: 테스트 50개 통과, 화면·시트 936가지(디자인 3 × 밝게·어둡게 × 휴대폰·태블릿 × 글자 보통·아주 크게) 오류·넘침 0, 뒤로 가기·끌어내리기 동작 시험 6개 통과.
