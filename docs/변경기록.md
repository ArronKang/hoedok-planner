## 2026-10-04 · 베타 1.1 — 영상으로 받은 버그 · 아이폰 기본 리퀴드 글래스 · 시작 화면

## 2026-10-04 · 베타 1.0 — 써 보고 막힌 곳 · 알맹이 채우기
사용자가 실제로 써 보고 남긴 말: 진도 단위가 쪽뿐(영어는 1-1, 1-2처럼) · 칸 채우기 · 디자인 깔끔하게, 막대에 이상한 것 넣지 말기 · **시작 쪽이 1이 아니면 쪽수가 제대로 안 들어감** · 아이폰에서 창 끌어내리면 끊김 · **숫자가 제대로 안 들어가는 곳이 많음** · ＋ 단추가 너무 위에 떠 있고 아래 막대가 너무 높음 · 아래 막대는 아이폰 리퀴드 글래스로(PC는 지금 디자인) · 과목을 바꿀 때 깜빡여 눈이 아픔 · 설정에 '화면'을 꾸미는 선택지가 없음 · 두 번 누르면 확대됨. 그리고 **겉이 아니라 알맹이** — 이제 베타(v1), 실제로 쓰는 메인 버전.
계획·검토 과정은 [개발-계획.md](개발-계획.md) '5차'.

**숫자 칸 — 보이는 값 = 저장된 값** (모든 숫자·날짜 칸을 새 칸 하나로: `NumField`·`RangeField`·`DateField`)
| 전에는 | 이제 |
|---|---|
| 몇 쪽까지 적기: 글자를 칠 때마다 범위로 고쳐서, 20쪽부터인 단계에 '2'를 치면 지워짐 → 25를 칠 수 없음 (**사용자가 말한 버그**) | 치는 동안은 그대로, 칸을 떠나거나 완료를 누를 때 확인 |
| 할 일 › 일부만: 31쪽부터인데 '3'을 치면 30으로, 이어서 '5' → 305 → 끝 쪽 | 같음 |
| 교재 범위: 시작 쪽을 지금 끝 쪽보다 크게 치면 **말없이 무시** (칸에는 친 숫자, 저장은 옛 값) | 끝 쪽이 같은 길이만큼 따라감 (1–60 → 70 → 70–129), 한 줄로 알려 줌 |
| 교재 범위를 고쳐도 이미 만든 단계는 옛 범위 그대로 | 그 교재를 쓰는 단계도 함께 바뀜. 한 진도는 새 범위 안이면 그대로 |
| 점수가 만점보다 크면 저장은 만점, 칸에는 친 숫자 | 맞춘 값으로 칸도 바뀌고 "100점까지라서 100점으로 맞췄어요" |
| 반영 비율·만점에 0이나 글자를 치면 무시 | "숫자만 적을 수 있어요" / 범위로 맞춤 |
| 시험 결과·모의고사: 등급 0, 백분위 140도 들어감 | 등급 1–9, 백분위 0–100, 원점수 0–100(한국사·통합사회·통합과학 0–50) |
| 오늘보다 앞 날짜를 고르면 무시, 칸에는 고른 날짜 | 되돌리고 "오늘 뒤의 날짜를 골라 주세요" |
- 칸을 누르면 전체 선택 → 바로 새 숫자를 치면 바뀜. 누르기만 하고 떠나면 아무것도 바꾸지 않음.

**진도 단위 — 교재마다** (쪽 · 지문 · 문제 · 강 · 회 · 단원)
- 교재 줄의 단위를 누르면 바꿈. 쪽은 '어디까지', 나머지는 **칸**을 골라 채움 (건너뛰며 보는 교재).
- **단원**은 이름을 붙일 수 있음: "큰 단원 2개 × 작은 단원 3개" → 1-1 … 2-3, 또는 직접 "1-1~1-4, 2-1~2-3, 쉬어가기". 할 일·진도에도 그 이름 그대로 ("1-1 ~ 1-3").
- 영어 교과서는 처음부터 단원, 변형문제는 지문, '인강'은 강, '모의고사 기출'은 회로 넣어 둠 (바로 바꿀 수 있음).
- 단위를 바꿔도 한 진도는 옮길 수 있는 만큼 옮김 (쪽 ↔ 번호). 단원 이름을 고쳐도 채운 칸은 이름으로 따라감.
- 단위가 섞인 과목: %는 걸리는 시간으로 무게를 줌 (1쪽 3분과 1강 40분을 같은 하나로 세지 않게), 남은 분량은 "22지문 · 단원 5개", 하루 몫은 예상 시간으로. 날짜별로 나눌 때도 시간이 고르게.
- 교재마다 '한 칸에 걸리는 시간'을 따로 (교재와 단계 고치기 맨 아래).
- 예전 기록(과목 전체가 '지문으로 세기')은 고쳐 쓰지 않고 그대로 읽음.

**진도 화면**
- 막대는 **채움만**: 한 만큼 과목 색, 안 한 곳은 같은 색을 옅게. 지금 단계 밑의 검은 줄·테두리를 뺌. 막대 아래 이름은 '1회독 · 2회독'처럼 짧게.
- 칸 교재는 과목 화면에서 칸(줄) × 회독(열) 표를 바로 눌러 채움. 30칸이 넘으면 앞부분만, '모두 보기'.
- 할 일 › 일부만: 칸 교재는 '몇 번까지' 대신 **한 칸을 골라 누르기** (건너뛴 번호도 맞게).
- 교재와 단계 고치기에서 범위·단위를 바꾸면 "남은 날에 다시 나누기"를 바로 누를 수 있게.

**할 일 추가**
- 과목을 고르면 **"10/4에 잡혀 있는 다음 것 · 오늘로 당겨 오기"** 한 줄 → 누르면 그 할 일을 오늘로 (겹치는 할 일을 새로 만들지 않음). 잡힌 게 없으면 지금 단계에서 이어서.
- 적는 예시도 지금 단계의 교재·단위로 ("평가문제집 p.31-40", "교과서 2-1~2-3").
- 과목 화면에서 ＋를 누르면 그 과목이 골라져 있음.

**아이폰**
- **창 끌어내리기를 기기 스크롤로** — 창 위쪽 빈 곳 + 창을 스크롤 상자에 쌓아서, 끌면 기기가 직접 움직임 (아이폰 기본 창처럼 120Hz, 놓으면 관성·튕김·제자리). 창 안 내용이 맨 위일 때 끌면 창이 함께 내려감. 창은 아래에서 끝까지 올라오고, 닫으면 아래로 내려감.
- **확대 끔**: 두 번 누르기·두 손가락·입력 칸 누를 때 확대 모두. 글자 크기는 설정 › 글자에서.
- 단추를 길게 눌러도 글자 고르기·확대경이 뜨지 않음 (입력 칸·메모는 그대로).

**아래 막대 · ＋ 단추**
- 아이폰은 **떠 있는 유리 막대**(리퀴드 글래스): 반투명, 내용이 뒤로 비쳐 지나감, 고른 탭 뒤의 둥근 렌즈가 새 탭으로 미끄러지며 잠깐 늘어났다 돌아옴. ＋는 막대와 **같은 줄 오른쪽**의 동그란 단추 (모든 탭에서 할 일 추가).
- PC·안드로이드는 지금 막대 그대로, 높이만 아이폰 기본에 가깝게 (≈98 → 85px). ＋는 막대 바로 위 16px (전에는 막대 높이를 한 번 더 더해서 혼자 높이 떠 있었음).
- 설정 › 탭 막대와 배치에서 자동 / 유리 / 기본, 탭 이름 보이기.
- 지금 탭을 한 번 더 누르면 처음 화면으로, 이미 처음이면 맨 위로.

**깜빡임 없애기 — 겹쳐 바뀜**
- 과목·탭·날짜를 바꿀 때 옛 화면이 한순간에 사라지고 새 화면이 서서히 나타나던 것(그 빈 순간이 깜빡임) → 옛 화면의 복사본을 그 자리에 겹쳐 두고 흐려지는 동안 새 화면이 나타남.
- 설정 안쪽으로 들어가면 오른쪽에서 밀려 들어오고 뒤로 가면 왼쪽에서 (아이폰 설정처럼).

**설정 — 애플 설정처럼**
- 맨 위 계정 카드, 그 아래 **화면** 묶음을 앞에. 줄마다 색 아이콘, 오른쪽에 지금 값.
- 새로 고를 수 있는 것: **강조 색**(디자인 색 + 8가지, 디자인마다 밝기를 맞춰 둠) · **굵은 글씨** · 글자 크기('가' 크기로 바로 보임) · **탭 막대 모양·이름** · **앱을 열면 볼 화면**(오늘/진도/성적/마지막 화면) · **끝낸 일**(그 자리에/아래로/숨기기) · **D-day 모양**(D-11 / 11일 남음) · **할 일 줄에 예상 시간** · **과목 줄의 숫자**(퍼센트/분량) · **달력 첫 요일** · **시각 표시**(24시간/오전·오후) · **체크할 때 진동**(되는 기기만).
- 화면 및 밝기·글자 쪽 맨 위에 **견본** — 고르는 즉시 실제로 어떻게 보이는지.
- 기록 관리(내보내기·불러오기·지우기)를 한 곳에, **정보**에 버전 '베타 1.0'과 쓰는 법.

**오늘 화면**
- 상황일 때만 뜨는 알림 줄을 상자 여러 개 대신 **한 장에** 모음.
- 휴대폰에서는 목록 끝의 점선 '할 일 추가'를 뺌 (＋가 있으므로).

**점검**: 테스트 87개 통과 (단위·범위·단원 이름·으로/로 새로 15개). 화면 전수 점검에 새 화면 15개(칸 채우기·교재 고치기·단원 이름·설정 쪽마다) + 유리/기본 막대 + 굵은 글씨를 더함.
**사용자 기기에서만 확인할 수 있는 것**: 창 끌어내리기 느낌(아이폰), 유리 막대 모양, 확대 안 됨, 진동(갤럭시).

**동기화 (계정 · 동기화)**
| 무엇 | 왜·어떻게 |
|---|---|
| 서버 주소·공개 키를 앱에 넣어 두면(`src/config.js`) 계정 화면에 **이메일·비밀번호·로그인만** | 개발자 말(Project URL, anon key)을 없앰. 가입 단추도 숨김 — 계정은 서버 관리 화면에서 한 번 만들고 새 가입은 서버에서 막음 |
| **예시 기록은 계정에 절대 안 올라감** | 예시를 보는 동안은 동기화를 멈춤. 예시 기기에서 로그인하면 "예시 지우고 로그인". 표시가 생기기 전에 연 예시도 알아봄 |
| 로그인한 뒤 처음 맞추면 **"계정에서 과목 N개 · 할 일 M개를 받아 왔어요"** | 새 기기에서 기록이 다 들어왔는지 알 수 있게. 처음 화면에서 로그인했으면 기록이 들어온 뒤 창이 저절로 닫힘 |
| 로그인이 풀리거나 12시간 넘게 못 맞추면 **설정 단추에 빨간 점** | 평소에는 아무것도 안 보임. 인터넷이 없을 뿐이면 점 없음 |
| 로그인할 때 이 기기 기록을 모두 다시 올림 | 서버를 새로 만들었거나 비었어도 다시 채워짐 (서버는 더 새로운 것만 받으니 겹치지 않음) |
| **미리 보기에서도 로그인** — 같은 계정, 기록 공간은 따로(`preview:`) | 동기화를 미리 보기로 먼저 써 볼 수 있게. 실제 앱 기록을 받지도 올리지도 않음 |
| 비밀번호를 잊었을 때: 메일 대신 관리 화면에서 바꾸는 법 | 메일 링크가 앱으로 돌아오지 않아 끝까지 못 갔음 |
| 아이폰 Safari에서 계정 화면 → "아이콘으로 연 앱에서 로그인" 안내 | Safari와 아이콘 앱은 기록이 따로 |
| 서버 오류를 한국어로 ("새 가입을 받지 않아요", "로그인이 풀렸어요", "서버가 잠시 응답하지 않아요" …) | 영어가 그대로 나오던 것 |
