# 동기화 체크리스트

기록이 사라지거나 섞이는 것이 이 앱에서 가장 나쁜 버그다. 동기화를 고치면 이 목록을 다시 확인한다.
- **자동**: `tests/sync.node.test.js` (노드 테스트에 포함)
- **두 기기**: 가짜 서버로 PC에서 두 기기를 흉내 낸다
  - `python tools/fake_supabase.py 54321 --dump --no-signup` → `http://127.0.0.1:54321`, 키 `test-anon-key`
  - 기기 A = `http://localhost:5173/`, 기기 B = `http://127.0.0.1:5173/` (저장 공간이 따로)
  - 앱에 넣어 둔 서버처럼 보려면 시험하는 동안만 `src/config.js`에 가짜 서버 주소·키를 넣는다 (**커밋하지 말 것**)
  - 서버에 무엇이 들어갔는지: `http://127.0.0.1:54321/__dump`
- **기기**: 사용자가 실제 서버(Supabase)로 휴대폰·태블릿에서

## C. 맞추기
| # | 확인 | 방법 |
|---|---|---|
| C1 | 한 기기에서 체크 → 다른 기기의 할 일과 진도 %가 같이 바뀐다 | 두 기기 |
| C2 | 같은 할 일을 두 기기에서 고치면 나중에 고친 쪽이 남는다 (먼저 올린 쪽이 나중이어도) | 두 기기 |
| C3 | 지운 할 일은 다른 기기에서도 지워지고, 처음부터 다시 받아도 살아나지 않는다 | 두 기기 |
| C4 | 인터넷이 끊긴 동안 고친 것은 대기열에 남았다가, 다시 되면 올라간다 | 두 기기 (요청 실패 흉내) |
| C5 | 반복하는 일: 두 기기가 각자 만들어도 같은 날 것은 하나 (같은 id), 서버에도 하나 | 두 기기 |
