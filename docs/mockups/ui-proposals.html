회독 진도를 그리는 세 가지 방법

같은 데이터(섹션 이름 + 교재 + 페이지 범위 + 완료 쪽수)를 화면에 어떻게 그릴지에 대한 안입니다. 색과 글꼴은 셋 다 똑같이 맞춰 뒀으니 구조만 비교해서 골라 주세요.

구조 변경: 트랙을 시험 화면 안에 넣어 뒀던 걸 하단 탭 최상위로 뺐습니다 — 오늘 · 트랙 · 성적 · 분석 · 설정. 보내주신 그림과 같습니다.
한 가지 뺀 것: 그림에 있던 "현재 속도 완료 10/16"은 넣지 않았습니다. 인수인계서의 예측 금지 규칙에 걸립니다. 대신 남은 분량 · 남은 일수 · 지금까지 일평균 · 필요 처리량 네 숫자만 나란히 둡니다.
안 A

진도 띠

답하는 질문 — "어디까지 왔나?"

보내주신 스케치 그대로입니다. 띠 하나가 과목 하나고, 띠를 회독 섹션으로 나눕니다. 칸 너비가 실제 분량(쪽수)에 비례하므로 "6개 중 2개 끝"이 아니라 "220쪽 중 75쪽"이 눈에 보입니다. 검은 세로선이 지금 위치입니다.

제 추천 — A를 기본으로, C를 트랙 홈에

셋 다 같은 데이터를 쓰기 때문에 하나만 고를 필요가 없습니다. 이미 만들어 둔 계산 로직이 섹션 · 페이지 범위 · 완료 쪽수를 그대로 내주고 있어서, 그리는 방식만 갈아 끼우면 됩니다.

과목 하나를 볼 때는 A(띠)가 맞습니다. 말씀하신 그림이기도 하고, 칸 너비가 분량에 비례해서 "얼마나 남았나"가 가장 정직하게 보입니다. 트랙 탭을 처음 열었을 때는 C(보드)로 시험 전체를 먼저 보여주고, 과목을 누르면 A로 들어가는 흐름입니다.

B(겹)는 버리기 아깝습니다. "5·6단원을 한 번밖에 안 봤다"는 건 A·C 어디에도 안 나오는 정보고, 이게 원래 말씀하신 자기 객관화에 가장 가깝습니다. A 상세 화면 안에서 띠 ↔ 겹 전환으로 넣으면 입력 부담 없이 원할 때만 볼 수 있습니다.
