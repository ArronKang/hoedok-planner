띠를 접었다 편다

안 A(진도 띠)를 뼈대로 두고, 화면을 새로 늘리지 않으면서 B와 C의 장점만 넣었습니다. 과목 카드를 접으면 C(비교), 펴면 A(상세), 상세 안에서 전환하면 B(깊이)입니다.

C 흡수 과목끼리 비교

접힌 카드는 이름 + % + 띠만 남습니다. 높이가 낮아서 과목 6개가 한 화면에 들어와요. 보드를 따로 만들 필요가 없어집니다.

B 흡수 어디를 몇 번 봤나

상세에 [띠 ǀ 겹] 전환을 답니다. 띠 화면에도 "1회독만 한 구간"을 한 줄로 띄워서, 겹을 안 열어도 놓치지 않게 합니다.

B 단점 제거 단원 입력 없음

섹션마다 이미 페이지 범위를 받고 있어서 겹을 자동으로 계산합니다. 기본값은 "범위 전체"라 대부분 손댈 필요가 없어요.

아이폰 — 같은 화면, 세 단계

화면 이동이 없습니다. 카드를 누르면 그 자리에서 펴지고, 다시 누르면 접힙니다. 띠 순서를 건너뛰며 공부해도(3회독 먼저) 섹션마다 따로 채워지니 어긋나지 않습니다.
